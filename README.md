# SETCO Premium Website

Premium bilingual corporate website for SETCO, Smart Economy for Trade and Import.

## Features

- English and Arabic website content
- Animated SETCO opening sequence
- Responsive homepage, services and contact pages
- Premium business enquiry form
- Original optimized website imagery
- HTC partner section
- SEO metadata, canonical URLs and social sharing metadata
- Organization structured data
- Generated `robots.txt` and `sitemap.xml`
- Responsive and reduced-motion support

## Technology

- React 19
- Next.js 16
- Vinext and Vite
- TypeScript
- Cloudflare deployment support

## Local development

Node.js 22.13 or newer is required.

```bash
pnpm install
pnpm dev
```

Open the local URL printed in the terminal.

## Production build

```bash
pnpm build
```

## Main routes

- `/` homepage
- `/services` smart devices, distribution and HTC partnership
- `/contact` business enquiry page
- `/robots.txt` crawler directives
- `/sitemap.xml` search-engine sitemap
